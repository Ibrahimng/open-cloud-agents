# Docker & Containerization Skills

Curated agent skills for building lean, secure, and production-ready container images.

## Target Skill Areas
- **`dockerfile-hardening`**: Multi-stage builds, non-root user execution, minimal distroless/alpine base images.
- **`container-security-trivy`**: Vulnerability scanning of layers and software bill of materials (SBOM) generation.
- **`docker-compose-environments`**: Local multi-container development and test environments with volume mounts and networks.
