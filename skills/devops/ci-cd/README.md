# CI/CD & GitOps Delivery Skills

Curated agent skills for automating build, test, and release promotion pipelines.

## Target Skill Areas
- **`github-actions-hardening`**: OIDC federation (no static cloud keys), least-privilege token permissions, and reusable workflows.
- **`gitops-argocd-promotion`**: Multi-environment promotion (`dev` ➔ `uat` ➔ `prod`) and sync wave orchestration.
- **`canary-progressive-rollouts`**: Automated rollback metrics, Argo Rollouts, and traffic splitting policies.
