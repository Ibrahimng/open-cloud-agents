# Observability & SRE Skills

Curated agent skills for monitoring distributed systems, querying metrics, and managing incident triage.

## Target Skill Areas
- **`opentelemetry-instrumentation`**: Tracing context propagation, span attributes, and metric exporters.
- **`promql-golden-signals`**: Constructing PromQL queries for latency (p99/p95), error rate, saturation, and traffic.
- **`sli-slo-burn-rate`**: Designing multi-window, multi-burn-rate alerting rules to prevent alert fatigue.
