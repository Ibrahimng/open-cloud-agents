# DevOps & Cloud Infrastructure Skills

Curated agent skills covering the delivery lifecycle from Infrastructure as Code to Kubernetes runtime orchestration and observability.

## Subdomains
- [`iac/`](./iac/): Terraform, OpenTofu, Pulumi, CloudFormation, and Bicep.
- [`kubernetes/`](./kubernetes/): Workload deployment, pod debugging, RBAC, and Helm templating.
- [`docker/`](./docker/): Multi-stage Dockerfiles, image minimization, and vulnerability scanning.
- [`ci-cd/`](./ci-cd/): GitHub Actions, GitLab CI, ArgoCD GitOps, and progressive delivery.
- [`observability/`](./observability/): OpenTelemetry, Prometheus (PromQL), Grafana dashboards, and Golden Signals.
