# MLOps Agent Skills

Curated agent skills for machine learning pipeline automation, model governance, and production serving.

## Target Skill Areas
- **`model-serving-fastapi-triton`**: Low-latency model inference servers with batching and GPU acceleration.
- **`ml-pipeline-orchestration`**: Kubeflow, Vertex AI Pipelines, or AWS SageMaker Step Functions execution.
- **`model-monitoring-drift`**: Detecting feature drift, prediction drift, and schema corruption in production.
