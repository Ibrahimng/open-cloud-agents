# Compliance & Audit Skills

Curated agent skills for automated compliance auditing, evidence gathering, and security benchmarking.

## Target Skill Areas
- **`cis-benchmark-audit`**: Automated inspection of cloud configurations against CIS Foundation Benchmarks.
- **`soc2-evidence-collector`**: Generating audit-ready evidence for access reviews, change management, and encryption at rest/transit.
- **`owasp-top-10-checks`**: Pre-merge code scanning and WAF rule alignment against OWASP vulnerabilities.
