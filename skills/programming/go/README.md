# Go Agent Skills

Curated agent skills for Go development, emphasizing high-throughput concurrency, idiomatic interfaces, and robust systems programming.

## Target Skill Areas
- **`go-concurrency-patterns`**: Goroutines, channels, sync primitives, worker pools, and context cancellation.
- **`go-microservice-scaffold`**: Standard project layout, slog structured logging, and HTTP/gRPC routing.
- **`go-testing-benchmarks`**: Table-driven testing, subtests, race detector verification, and benchmark profiling.
