# JavaScript & TypeScript Agent Skills

Curated agent skills for JavaScript and TypeScript development across client and server runtimes (Node.js, Bun, browser).

## Target Skill Areas
- **`typescript-strict-patterns`**: Generic constraints, discriminated unions, and branded types.
- **`node-microservices`**: Fastify/Express patterns, stream processing, and graceful teardowns.
- **`vitest-testing`**: Unit and integration test orchestration with modern mocking.
- **`esm-package-management`**: Clean ESM exports, monorepo workspaces (pnpm/npm), and build tooling.
