## ✍️ How to Add Yourself

When submitting a Pull Request:
1. Sign off your commits using Git DCO (`git commit -s`).
2. Fill out the **Contributor Sign-Off** block in your pull request.
3. Add a row to the **Community Contributors** table above in [`CONTRIBUTORS.md`](./CONTRIBUTORS.md).
4. See [`CONTRIBUTING.md`](./CONTRIBUTING.md) for privacy guidelines regarding public emails versus GitHub privacy aliases.
